# ImpactVault · UI/UX specification

Version 1.0 · 31 October 2026

A mobile-first responsive web application with a **Calm Wealth + Transparent Impact** identity. Users deposit USDC principal and direct separately funded eligible donation proceeds toward one of two pools.

## Read first

The worked demo has **3.00 USDC of user principal** and **0.20 USDC of sponsor-funded demo donation proceeds**. The sponsor contribution is not investment return or yield. Routing that contribution must leave the user's principal ledger at 3.00 USDC. Keeping balances separate does not guarantee recovery or insure principal.

Only **Hunger Relief** and **Kalimantan Forest Fire Relief** appear as donation pools. Pool names describe intended purposes; they do not establish charity verification, actual beneficiaries, or completed impact.
